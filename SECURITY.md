# Security

Report vulnerabilities privately to support@sendrepute.com with version,
impact and a minimal redacted reproduction. Do not attach customer messages,
credentials or unredacted logs. Coordinate disclosure before opening a public
exploit report. No response-time SLA is promised. Version 0.1.x is the supported
source line.

Keep keys in server secrets, use verified HTTPS and exact trusted hostnames.
Both paid consent and mail-hook enablement are opt-in; each message must also
opt in. Test blocking/failure policy on transactional mail. Protect configuration
caches and do not log content or authorization headers.
